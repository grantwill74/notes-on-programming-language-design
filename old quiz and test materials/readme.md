# Old quiz and test materials

This directory stores old semesters' outcome quizzes and their keys when available. These are in markdown format for universal accessibility: if you want to make quizzes based on these, you can use pandoc to generate a PDF from them. 

For my students, the easiest way to use these practice samples is to open them in a markdown-supporting editor such as VS code. You can then open a preview by rightclicking the file in the file browser to the left and selecting "Open Preview".

The problems are just named after the order the appeared, the number is otherwise not meaningful.
