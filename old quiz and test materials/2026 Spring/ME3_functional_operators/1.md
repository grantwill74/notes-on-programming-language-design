# ME 3 Quiz

**Include types for all of these functions**. 25% for each question. You may use only standard library functions or functions you define here. Only Haskell responses will be accepted.


1. Define a **point-free** function `whichEven` which returns which elements of a list of `Ints` are even. For example, `whichEven [1,2,4,3] == [False, True, True, False]`
2. Define a **point-free** function `any` which takes a list of bools and returns true when at least one is `True`. You may not use the built-in `any` function. (Hint: use one of the `fold`s)
3. Define a **point-free** function `anyEven` which takes a list of `Ints` and returns true if at least one of them is even.
4. Define a **point-free** function `noEven` which takes a list of `Ints` and returns true if *none* of them are even.
