# ME 3 Question

**Include types for all of these functions**. 25% for each question. You may use only standard library functions or functions you define here. Only Haskell responses will be accepted.

1. Define a function *point-free* named `hasTenth` that returns whether a `[a]` has a tenth item (meaning a length of at least 11)   
2. Define a function named `swapPair` which takes a pair of type `(a, b)` and swaps its values into a `(b, a)`. 
3. Define a function named `everyOther` which takes a unary function `(a -> a)` and runs it on every other element of the list, starting with the initial element. So `everyOther (+1) [1,2,3,4] == [2,2,4,4]`
4. Then define a function that takes two `[a]`s and swaps their even indices. So `swapEvens [1,2,3,4] [6,7,8,9] == ([6,2,8,4], [1,7,3,9])`. Hint: you can use `zip`, `everyOther`, `swapPair`, and `unzip`.

2, 3, and 4 don't have to be point-free.
