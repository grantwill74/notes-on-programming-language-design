# ME 2 Quiz

**Include types for any functions you define**. 25% for each question. You may use only standard library functions or functions you define here. Only Haskell responses will be accepted.

1. Define a datatype which has two constructors: one which takes a single `Int` and one which takes two `Int`s.
2. Define a function that takes an `Int` and returns an instance of the data type you created in problem 1. If the `Int` is odd use the single constructor, if it is even, use the pair constructor. You can choose the values to give to the constructor.
3. Define a function `everyThird` that takes a list of *any* type the user of your function chooses and returns a list of every third value starting with the zeroth one. For example `everyThird [1,2,3,4,5,6,7,8,9] == [1,4,7]`
4. Define a function `stripEmpty` that takes a list of `Strings` and removes the empty ones. `stripEmpty ["hello", "", "world", "!"] == ["hello", "world", "!"]`

Remember to include types for any functions you define!
