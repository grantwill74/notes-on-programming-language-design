# ME 2 quiz

Each problem is worth 25%. 

1. Define a lambda function named `atLeastOneOf3` which takes three Church booleans and returns whether at least one of them is true. You may assume Church booleans `True` and `False` are defined, but nothing else.
2. Evaluate this lambda expression (i.e., reduce it to normal form): ($\lambda$ `x` . $\lambda$ `y . y`) ($\lambda$ `z w . w z`)
3. Write 3 as a lambda numeral in normal form (i.e., show the most detailed function definition, don't just say like `2 + 1` or something)
4. Define a curried function in any programming language that takes two numbers and returns the absolute value of their difference.
