# ME 2 Question

Each problem is worth 25%. 

1. Define a lambda function `and3` which takes three church booleans and returns `True` only if all 3 are true. You may assume that `True` and `False` are defined but nothing else.
2. Expand `4 id` as a lambda expression in normal form. Show your work. 
3. Evaluate $\lambda$`f x . 3 f (2 f x)`, either into normal form or using numerals.
4. In any real programming language, write a curried function that takes three values. If the first value is negative, make it return the second value. If the first value is non-negative, make it return the third value.
